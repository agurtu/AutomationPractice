########### Create Pull Request (PR) ##################

1. Once we open server we will see "Compare & pull request" button in green color.

2. Click on "Compare & pull request" button.
   
3. Provide PR description : we have to provide all details about the pull request
   -> what changes we done.
   -> How many changes are affecting other
   -> Upload evidences. screenshots, video recording.

4. Click on Gear button of reviewer section  (right side)
   -> here we can add all reviewer who is going to review code and approval pull request.
   -> Click on gear icon -> select people to review code
   -> People will get email notification after creating the pull request.

5. Select assignee , it means owner of work done by.
   -> You can select your self as assignee.

6. click on Create pull request button.

7. create pull request will show Pull requests Tab.

################# Review Pull Request ######################

1. Go pull request tab open your dedicated pull request 
2. There are 4 tabs in pull request
   - conversation : -> It will show all review comments and merge pull request button.
                    -> Requester can resolve all the comments from this section.
                    -> Once got approval, requester has to click on merge pull request button to close the PR
                    -> One PR is merge changes will be available in main or target.

  - Checks : all CI/CD pipeline is going to visible on inside the check section.
  - Commits : All commits done by developer will show in this section.
  - File Changed : -> It will list down all the file where developer has done the changes.
                   -> Here it will show all updated lines in green or red color. (green : added line, red: removed lines)
                   -> Reviewer can submit the review from submit review button and provide approval.
